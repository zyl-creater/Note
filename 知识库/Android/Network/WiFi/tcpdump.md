`tcpdump` 是一个在类 Unix 系统中广泛使用的命令行工具，用于捕获和显示通过网络接口接收或传输的数据包。它支持多种协议，包括 TCP、UDP、ICMP 等，并且可以用于有线和无线网络。

`tcpdump` 的基本语法如下：
```sh
tcpdump [选项] [表达式]
```

一些常用的 `tcpdump` 选项包括：
- `-i <接口>`：指定要捕获数据的网络接口。
- `-n`：不将主机名解析为 IP 地址。
- `-nn`：不将主机名和端口名解析为 IP 地址和端口号。
- `-v`：输出更详细的信息。
- `-vv`：输出更更详细的信息。
- `-s <长度>`： 选项用于指定每个捕获的数据包的快照长度（snapshot length）。快照长度是指从每个数据包的开始捕获的字节数。
- `-c <数量>`：捕获指定数量的数据包后停止。
- `-w <文件>`：将捕获的数据包写入文件，用于离线分析。
- `-r <文件>`：从文件中读取之前捕获的数据包。

表达式用于过滤捕获的数据包。例如，你可以根据协议、源地址、目的地址、端口号等来过滤数据包。一些常用的表达式包括：
- `host <主机>`：仅捕获与指定主机相关的数据包。
- `src host <主机>`：仅捕获源地址为指定主机的数据包。
- `dst host <主机>`：仅捕获目的地址为指定主机的数据包。
- `port <端口>`：仅捕获指定端口号的数据包。
- `src port <端口>`：仅捕获源端口号为指定端口的数据包。
- `dst port <端口>`：仅捕获目的端口号为指定端口的数据包。

例如，如果你想要捕获接口 `eth0` 上的所有 HTTP 数据包，并显示更详细的信息，你可以使用以下命令：
```shell
tcpdump -i eth0 -v 'tcp port 80'
```

如果你想要捕获 100 个数据包，并将它们写入文件 `capture.pcap` 以供稍后分析，你可以使用以下命令：
```shell
tcpdump -i eth0 -c 100 -w capture.pcap
```

```shell
tcpdump -i wlan0 -vv -s 0 -w /sdcard/packets.cap
```
